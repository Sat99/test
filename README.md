# Klub Ada Website

A modern, responsive website for Klub Ada, built with HTML, CSS, and JavaScript.

## Features

- Responsive design that works on all devices
- Modern and clean user interface
- Interactive elements with smooth animations
- Form validation and submission handling
- Newsletter subscription
- Mobile-friendly navigation
- Blog section with pagination
- Events management system
- Partnership opportunities
- Team showcase
- Testimonials section

## Pages

1. Home (`index.html`)
2. About Us (`o-nas.html`)
3. Events (`dogodki.html`)
4. Blog (`blog.html`)
5. Partnership (`partnerstvo.html`)

## Setup

1. Clone the repository:
```bash
git clone https://github.com/Sat99/test.git
```

2. Open any of the HTML files in your browser to view the website.
